# Unity Code MCP Server 0.6.0 Release Changes

## TL;DR

- New **Setup & Status panel** at the top of the settings inspector (`Tools/UnityCodeMcpServer/Show or Create Settings`): see at a glance whether the server is listening and when a client last talked to it, and copy a ready-to-paste config for your MCP client.
- The settings panel **auto-opens once** on first install so a new user lands on the setup instructions instead of hunting for them.

## ✨ In-Editor Setup & Status

A `Setup & Status` section now renders above the existing settings:

- **Live status** — a `Server: Running / Stopped` row with a **Restart** button, and a `Last client request` row that shows how long ago the bridge last delivered a request (green when active within the last 15s, grey otherwise, or "none this session"). This is the in-Unity confirmation that the file transport is actually working, without digging through logs.
- **Copy-ready config** — three labelled, selectable blocks each with a **Copy** button, pre-filled with this machine's resolved `STDIO~` path and a project-derived server name:
  - **Claude Code** — the full `claude mcp add <name> -s local -- uv run --directory "…" unity-code-mcp-stdio --request-timeout 240` command.
  - **Codex** — a `[mcp_servers.<name>]` block for `~/.codex/config.toml` with `startup_timeout_sec`/`tool_timeout_sec` already set.
  - **Generic JSON** — the existing stdio server JSON.
- **First-run guidance** — on first install the settings asset is selected automatically (once per machine + project, skipped in batch mode), so the setup panel is the first thing you see.

The existing `Print MCP configuration to console` menu item is unchanged for anyone who prefers it.

## 🔌 Connection state API

`UnityCodeMcpFileServer` now exposes `IsServerRunning` and `LastRequestUtc` (backed by `SessionState`, so it survives domain reloads and resets per editor session). The last-request timestamp is recorded as each request is processed.

No tool behavior or runtime semantics changed. Update the package to pick up the new panel.
